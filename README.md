# ⚡ FinVision AI: Financial Research & Text-to-SQL Analytics

An enterprise platform combining **Option 5B (GenAI / RAG / Text-to-SQL)** powered by **Google Gemini**:
- **Qualitative RAG Engine**: SEC 10-K/10-Q filing ingestion and semantic analysis with verifiable citations.
- **Autonomous Text-to-SQL**: Converts business language into verified, read-only SQL queries over financial warehouses.
- **Modern Glassmorphic UI**: Streamlit web application with KPI cards, SQL schema exploration, and dynamic Plotly charts.
